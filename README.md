A complete chess engine in 3,995 bytes of Python, standard library only: 0x88 board, alpha-beta search with PVS, a transposition table and quiescence, deterministic fixed node search, packed with lzma as the rules allow.

## Run it

```sh
MAKEFUN_ENV_URL=<env origin> python3 main.py
```
